# Fake-and-Real-News-Detection
An NLP and Machine Learning project for detecting fake and real news articles using TF-IDF, SVM, ANN, word embeddings, BiLSTM, CNN, and Transformer-based models. Includes data preprocessing, model comparison, evaluation, and multi-dataset experimentation.
